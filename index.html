Anatomy of a web server · eight machines

GenHTTP, drawn as machines

GenHTTP is a C# web server whose Ioxide engine puts the socket work in the kernel: one io_uring reactor per core, kTLS, zero copies, HTTP/3, all behind the same four-method handler contract as the little embedded server it started as.

Each machine below is an interactive isometric figure. Hover it. Every part is drawn to the same truth as the code — the companion notes for each figure live in docs/, starting with why GenHTTP is god tier.

  1. Fig 1

    Ioxide — the io_uring exchange

    A telephone exchange: the call arrives at the panel, an operator (a reactor) picks it up, and the kernel — not the thread — holds the connection while the work is done.

    openlightnotes
  2. Fig 2

    The zero-alloc exchange

    A coin sorter: every request is a coin, and the gate decides — pooled request objects, memory-view headers with precomputed hashes, nothing handed to the garbage collector on the hot path.

    openlightnotes
  3. Fig 3

    The handler tree

    A signal box: points decide which track a request takes, and every track ends somewhere — a resource, or the error handler that catches whatever falls through.

    openlightnotes
  4. Fig 4

    The concern chain

    A filter stack: concerns screw onto the content one after another, first on is outermost, and the request passes through each in turn.

    openlightnotes
  5. Fig 5

    The reflection mapper

    A card catalog: methods become index cards — path, verb, parameters — read from the assembly once and filed where the router can find them.

    openlightnotes
  6. Fig 6

    The OpenAPI generator

    A surveyor: the theodolite walks the handler tree, sights each operation, and drafts the specification sheet from what it measures — no annotations twice.

    openlightnotes
  7. Fig 7

    Freshness and size

    A cloakroom: hand in a ticket (If-None-Match) and either your coat is still there — 304, nothing handed back — or you get it fresh, within the size the counter allows.

    openlightnotes
  8. Fig 8

    The turntable

    A engine shed turntable: three engines — Internal, Kestrel, Ioxide — on one pit; the deck turns and every coach (every test) couples to whichever engine is facing it.
