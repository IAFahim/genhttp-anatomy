How does a plain C# method become an HTTP operation?

Every front door — ServiceResource, Controller or an Inline lambda — ends in the same machinery: TypeAnalyzer reads the attributes into a MethodCollection and the OperationRouter matches the request card to one drawer. SignatureAnalyzer then binds each parameter by fixed precedence, so a bead drops only into the slot the signature declares.
